# Keyboard Shortcuts - DAIW

Complete reference for all keyboard shortcuts in DAIW (Digital AI Workspace).

**Note:** On macOS, replace `Ctrl` with `Cmd` (⌘) for most shortcuts.

## Customization

### How to Customize Shortcuts

1. **Open Settings:** `Ctrl+,`
2. **Navigate to:** Keyboard Shortcuts
3. **Find command:** Search or browse
4. **Click shortcut:** Shows current binding
5. **Press new keys:** New shortcut is recorded
6. **Save:** Shortcut updated

**Conflict Detection:**
- DAIW warns if shortcut already used
- Option to reassign
- Reset to defaults available

### Import/Export

**Export Your Shortcuts:**
```
Settings → Keyboard Shortcuts → Export
Saves to: shortcuts.json
```

**Import Shortcuts:**
```
Settings → Keyboard Shortcuts → Import
Choose: shortcuts.json file
```

**Share with team or sync across devices!**

## Platform-Specific

### macOS Shortcuts

On Mac, most `Ctrl` becomes `Cmd` (⌘):

| Windows/Linux | macOS | Action |
|---------------|-------|--------|
| `Ctrl+K` | `Cmd+K` | Command Palette |
| `Ctrl+S` | `Cmd+S` | Save Preset |
| `Ctrl+Z` | `Cmd+Z` | Undo |
| `Ctrl+,` | `Cmd+,` | Settings |

**Mac-Specific:**
- `Cmd+H` - Hide DAIW
- `Cmd+M` - Minimize
- `Cmd+Tab` - Switch apps (system)

### Linux Shortcuts

Standard `Ctrl` shortcuts work.

**Linux-Specific:**
- `Super+H` - Hide window (some DEs)
- `Alt+F4` - Close window (alternate)

## Tips & Tricks

### Efficiency Tips

1. **Learn Command Palette** (`Ctrl+K`)
   - Faster than memorizing all shortcuts
   - Fuzzy search is powerful
   - Shows shortcuts in results

2. **Use Number Keys** for Quick Mode Switching
   - `Ctrl+1` through `Ctrl+4`
   - Muscle memory develops quickly

3. **Global Shortcuts** for Always-Available Access
   - `Ctrl+Alt+Space` to summon DAIW
   - Works from any application

4. **Customize for Your Workflow**
   - Change shortcuts to match other tools
   - Create logical groupings
   - Use mnemonic devices

## Shortcut Conflicts

### Common Conflicts

**With System:**
- `Ctrl+Alt+Delete` (Windows Task Manager)
- `Cmd+Space` (Mac Spotlight)
- `Super` key (Linux launcher)

**With Other Apps:**
- DAWs may use same shortcuts
- Browser extensions
- System utilities

**Resolution:**
- Customize DAIW shortcuts
- Disable conflicting app shortcuts
- Use global shortcuts carefully
